# 机器学习算法1：线性回归

线性回归是机器学习中最基础的算法之一,用于预测连续型数值。

## 什么是线性回归

线性回归是一种监督学习算法,通过拟合一条直线(或超平面)来描述自变量和因变量之间的关系。

## 基本原理

线性回归模型假设输入特征 X 和输出 y 之间存在线性关系:

```
y = wX + b
```

其中:
- w: 权重(weight)
- b: 偏置(bias)

## 损失函数

线性回归通常使用均方误差(MSE)作为损失函数:

```
J(w,b) = (1/n) * Σ(y_pred - y_actual)²
```

## 梯度下降

通过梯度下降算法来优化参数,使损失函数最小化。

### 代码示例

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# 准备数据
X = np.array([[1], [2], [3], [4], [5]])
y = np.array([2, 4, 6, 8, 10])

# 创建模型
model = LinearRegression()

# 训练模型
model.fit(X, y)

# 预测
y_pred = model.predict([[6]])
print(f"预测值: {y_pred[0]}")
```

## 总结

线性回归是机器学习的入门算法,理解它对学习更复杂的算法非常重要。
