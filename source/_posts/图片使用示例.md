# 图片使用示例

本文演示如何使用 Hexo 的文章资源文件夹功能来方便地管理文章中的图片和其他资源文件。

## 什么是资源文件夹？

资源文件夹是一个与文章同名的文件夹，用于存放该文章相关的所有资源文件（如图片、视频、文档等）。例如：
- 文章：`图片使用示例.md`
- 资源文件夹：`图片使用示例/`

## 功能配置

在 `_config.yml` 中已经启用了资源文件夹功能：

```yaml
post_asset_folder: true
```

## 图片引用方式

### 方式 1: 标准 Markdown 语法（推荐）

```markdown
![风景图片](landscape.jpg)
```

这是最简单的方式，Hexo 会自动在资源文件夹中查找图片。

### 方式 2: 相对路径引用

```markdown
![风景图片](./图片使用示例/landscape.jpg)
```

### 方式 3: 使用 asset_img 标签

如果安装了 `hexo-asset-image` 插件，还可以使用：

```markdown
{% asset_img landscape.jpg 风景图片 %}
```

### 方式 4: HTML 标签

```html
<img src="/图片使用示例/landscape.jpg" alt="风景图片">
```

## 使用步骤

1. **创建文章**
   ```bash
   hexo new "文章标题"
   ```
   这会同时创建文章文件和同名资源文件夹。

2. **添加资源文件**
   将图片、文档等文件放入资源文件夹中。

3. **在文章中引用**
   使用上述任一方式引用资源。

## 示例展示

假设在 `图片使用示例/` 文件夹中有以下文件：
- `demo.jpg` - 示例图片
- `code.pdf` - 相关文档
- `data.xlsx` - 数据表格

### 引用示例图片

```markdown
这是示例图片：
![示例图片](demo.jpg)
```

显示效果：
![示例图片](demo.jpg)

### 链接到其他资源

```markdown
- [查看相关文档](code.pdf)
- [下载数据表格](data.xlsx)
```

## 最佳实践

1. **命名规范**：使用有意义的文件名，避免中文和特殊字符
2. **文件大小**：压缩图片以优化加载速度
3. **文件夹整理**：每篇文章一个独立文件夹，便于管理
4. **备份**：资源文件夹是博客内容的一部分，记得同步备份

## 注意事项

- 资源文件夹名称必须与文章文件名完全一致
- 文章文件名和资源文件夹名都不要包含特殊字符
- 建议图片文件使用小写英文名称

## 总结

使用资源文件夹功能可以让博客资源管理更加清晰和方便，是推荐的最佳实践。
