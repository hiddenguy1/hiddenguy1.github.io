# 图片引用示例

## 本文件夹用于演示图片引用方式

## 文件列表

请在实际使用时，将图片文件放入此文件夹：

- `demo.jpg` - 示例图片（请添加）
- `photo1.jpg` - 照片1（请添加）
- `photo2.jpg` - 照片2（请添加）
- `icon.png` - 图标（请添加）

## 在文章中引用这些图片

### 1. 引用 demo.jpg

```markdown
这是示例图片：
![示例图片](demo.jpg)
```

### 2. 引用 photo1.jpg

```markdown
![照片1](photo1.jpg)
```

### 3. 引用 photo2.jpg

```markdown
![照片2](photo2.jpg)
```

### 4. 引用 icon.png

```markdown
![图标](icon.png)
```

## 添加图片的步骤

1. 准备图片文件
2. 将图片复制到此文件夹
3. 在 `图片使用示例.md` 文章中使用上述语法引用
4. 运行 `npm run dev` 预览效果

## 注意事项

- 确保图片文件名与引用代码中的文件名一致
- 建议使用小写英文字母命名
- 支持的格式：jpg, png, gif, svg, webp
