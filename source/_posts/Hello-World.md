# Hello World

欢迎来到我的博客!

这是使用 Hexo 搭建的第一篇文章。

## 快速开始

```bash
# 安装 Hexo
npm install -g hexo-cli

# 初始化博客
hexo init blog
cd blog

# 安装依赖
npm install

# 启动服务器
hexo server
```

## 写作

创建新文章:

```bash
hexo new "文章标题"
```

更多内容请查看其他文章。
